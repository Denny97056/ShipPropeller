# 推力從哪裡來，效率又丟到哪裡去

螺旋槳把一團水往後推，水的動量增加多少，推力就有多大。這一篇先用最粗的模型（致動盤）找出效率的上限，再回到葉剖面，用速度三角形把推力和扭矩拆到每一個半徑上，最後積分成設計時天天在查的敞水曲線。

例子是 Wageningen B 系列的迴歸多項式，以及第一篇的 DTMB 4119。先從最直觀的量開始：槳每轉一圈，實際前進了多少。拖動進速比 $J$，看螺距線和實際前進的差（滑脫）怎麼變，以及 B4-70 的推力、扭矩與效率跟著怎麼走。
