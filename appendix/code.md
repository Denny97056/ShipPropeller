# 程式與驗證

每個模組都可以直接執行（`python code/模組名稱.py`），會印出它的驗證案例與結果。一次執行全部：

```bash
python tools/run_validations.py
```

| 篇 | 模組 | 內容 | 主要驗證 |
|---|---|---|---|
| 一 | `prop_geometry.py` | DTMB 4119 徑向分布的內插、*a* = 0.8 平均線、展開與投影面積比 | 平均線最大拱度 0.0679（*C*{sub}`Li` = 1）、內插通過原始表格、EAR 與標稱 0.60 相差 2% 內、PAR < EAR |
| 二 | `prop_momentum.py` | 致動盤理想效率、Wageningen B 系列迴歸式（39＋47 項）、DTMB 4119 的葉素–動量理論（Prandtl 葉尖修正） | 致動盤恆等式；*a* = 0.8 平均線理想攻角 1.54°；B 系列重現 MIT 2.611 兩個例題（B5-75 最佳 *P/D* = 1.0、*J* = 0.64／0.74、*η*{sub}`0` = 0.61／0.67）；葉素–動量理論收斂、設計點效率與試驗 0.69 相差 0.02 內，*K*{sub}`T` 高估 30–60%（缺升力面修正，第三篇處理） |

互動圖（`prototypes/`）裡的 JavaScript 用和這些模組相同的公式與內插方法，數值一致（例如三葉 EAR = 0.607、PAR = 0.500；DTMB 4119 在 *J* = 0.833 的 *K*{sub}`T` = 0.215、*η*{sub}`0` = 0.700）。
