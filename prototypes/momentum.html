船用螺旋槳　第二篇　動量與葉素理論

推力從哪裡來，效率又丟到哪裡去

螺旋槳把一團水往後推，水的動量增加多少，推力就有多大。這一篇先用最粗的模型（致動盤）找出效率的上限，再回到葉剖面，用速度三角形把推力和扭矩拆到每一個半徑上，最後積分成設計時天天在查的敞水曲線。

例子是 Wageningen B 系列的迴歸多項式，以及第一篇的 DTMB 4119。先從最直觀的量開始：槳每轉一圈，實際前進了多少。

2.1致動盤：推力就是動量的增加

先把螺旋槳想成一片很薄、會讓水壓突然升高的圓盤，不管葉片的形狀。穿過圓盤的水被加速，流管往下游收縮。對流管用動量守恆與白努利方程，可以得到圓盤處的速度增量正好是遠方尾流增量的一半：

Vdisk = VA(1 + a)，Vwake = VA(1 + 2a)
CT = T / (½ρAVA²) = 4a(1 + a)

有用功率是 T VA，槳交給水的功率是 T VA(1 + a)，所以理想效率

ηi = 1/(1 + a) = 2 / (1 + √(1 + CT))

這是任何推進器都超越不了的上限，損失的部分是留在尾流裡的動能。負載越重（CT 越大），要把水加速得越多，效率越低。要降低 CT，最直接的辦法是加大直徑：同樣的推力分給更多的水。

致動盤假設流體無黏、推力均勻分布在盤面上、尾流不旋轉。下一節的葉素理論會把旋轉和黏性損失加回來。

2.2速度三角形：一個剖面看到什麼

回到葉片本身。在半徑 r 的剖面上，水從前方以 VA 流來，剖面本身以 ωr 轉動。兩者合成的角度叫進角 β：

tan β = VA / (ωr) = J / (π r/R)

槳在推水，水也反過來被槳帶動：軸向多了 a VA，切向被帶著轉了 a′ωr。剖面真正看到的相對速度 W 方向是誘導進角 βi，攻角是螺距角減去它：α = φ − βi。

升力 dL 垂直於 W，阻力 dD 沿著 W，投影到軸向和切向就是推力與扭矩：

dT = dL cos βi − dD sin βi
dQ = r (dL sin βi + dD cos βi)

把這個剖面的效率 dT VA / (dQ ω) 整理一下，正好拆成三個因子：軸向損失 1/(1 + a)（就是致動盤的那一項）、尾流旋轉損失 1 − a′，以及黏性損失 tan βi / tan(βi + γ)，其中 tan γ = CD/CL。

本節的 a、a′ 是 DTMB 4119 用下一節的葉素–動量理論解出來的值。

2.3葉素–動量理論：把整支槳積分起來

前一節的 a 和 a′ 要怎麼求？把槳盤切成一圈一圈的環，每個環同時滿足兩件事：葉剖面算出來的力（上一節），要等於這個環的動量變化（2.1 的致動盤，只是換成一個環）：

dT = 4πr ρ VA² (1 + a) a F dr
dQ = 4πr³ ρ VA ω (1 + a) a′ F dr

兩組式子各自有 a、a′，反覆代入直到收斂。F 是 Prandtl 葉尖修正：葉數有限，水會從葉尖繞過去，越靠近葉尖，動量理論高估得越多。

積分後用無因次係數表示：

KT = T / (ρn²D⁴)，KQ = Q / (ρn²D⁵)
η0 = J KT / (2π KQ)

和 DTMB 4119 的試驗比較：在設計點 J = 0.833，效率算得很準（0.70 對 0.69），但 KT 和 KQ 都高估了四成多。原因是剖面用了二維翼型的升力：寬葉片上的流線是彎的，實際的有效拱度和攻角都比較小。第三篇的升力線理論會處理這件事。

剖面升力用薄翼理論 CL = 2π(α − α0)，零升力角 α0 由 a = 0.8 平均線積分而得（CLi = 1 時為 −7.58°），再乘上各半徑的 CLi；阻力係數沿半徑取定值。

2.4敞水曲線與 B 系列：用圖表選槳

敞水曲線是槳在均勻來流中的「身分證」：橫軸 J，縱軸 KT、10KQ 和 η0。J 小代表重負載（推力大、效率低），J 接近 P/D 時推力趨近於零。

Wageningen B 系列是荷蘭 MARIN 系統化試驗的一百多支模型槳。Oosterveld 與 van Oossanen（1975）把結果迴歸成多項式，KT 有 39 項、KQ 有 47 項：

KT = Σ Ck Js (P/D)t (AE/A0)u Zv

典型的選槳問題：已知船速（換成進速 VA）、需要的推力 T 和直徑 D，求轉速和螺距。把 n 消掉，

KT / J² = T / (ρD²VA²)

右邊是已知的常數，所以設計點一定落在拋物線 KT = c J² 上。每個 P/D 和拋物線各有一個交點，挑效率最高的那個。

迴歸式的適用範圍是 Z = 2–7、AE/A0 = 0.30–1.05、P/D = 0.5–1.4，雷諾數 2×10⁶。預設值重現 MIT 2.611 講義的例題：B5-75、KT/J² = 0.544，最佳 P/D = 1.0、J = 0.64、η0 = 0.61。

葉數 Z

計算方法與 prop_momentum.py 相同：致動盤用一維動量理論；B 系列用 Oosterveld & van Oossanen 的 39＋47 項迴歸式（雷諾數 2×10⁶），重現 MIT 2.611 講義的兩個例題；葉素–動量理論用 40 個半徑元素、Prandtl 葉尖修正，DTMB 4119 幾何沿用第一篇的內插。設計點 J = 0.833 算得 KT = 0.215、10KQ = 0.406、η0 = 0.700（試驗 0.146、0.280、0.69）。
