船用螺旋槳　第一篇　幾何與描述

一片葉子怎麼長在螺旋面上

螺旋槳的每一片葉子，都可以用幾條沿半徑變化的曲線完整描述：螺距、弦長、厚度、拱度、側斜與縱傾。這一篇把它們一個一個拆開，看每個數字在幾何上代表什麼，以及設計者為什麼這樣選。

例子是經典的 DTMB 4119 三葉槳：無側斜、無縱傾，P/D 約 1.08，是許多數值方法拿來驗證的標準槳。

葉數 Z

1.1螺旋面：剖面躺在哪裡

用一個和槳軸同心、半徑 r 的圓柱去切葉片，切口就是這個半徑上的葉剖面。把圓柱沿母線剪開、攤平，剖面的弦線落在一條斜線上：槳轉一圈，這條線沿軸向前進一個螺距 P。

tan φ = P / (2π r)

φ 是螺距角。同一個 P 在不同半徑對應不同的角度：靠近轂的剖面又陡又斜，葉尖幾乎平躺。所以即使螺距沿半徑不變，葉片看起來也是扭的。

習慣上用 0.7R 處的螺距代表整支槳，寫成螺距比 P/D。DTMB 4119 在 0.7R 是 1.084，從轂到葉尖只由 1.105 降到 1.076，幾乎是定螺距槳。

這裡的 P 用弦線（導緣到隨緣的連線）定義。舊式圖面常以葉面（壓力面）定義，對有拱度的剖面兩者略有差別。槳每轉實際前進的距離比 P 短，差額叫滑脫，第二篇再談。

1.2葉剖面：厚度和拱度各管一件事

攤平後的剖面就是一個二維翼型，用弦長 c、最大厚度 t、最大拱度 f 三個數描述。厚度主要提供強度，拱度主要提供升力。

船用螺旋槳最常見的組合是 NACA 66 (mod) 厚度分布配 NACA a = 0.8 平均線。a = 0.8 的意思是：從導緣到 80% 弦長，葉背與葉面的壓力差維持定值，之後線性降到零。拱度和設計升力係數成正比：

CLi = (f/c) / 0.0679
ΔCp = CLi / 0.9（x/c ≤ 0.8）

壓力差攤平，就沒有尖峰。葉背的最低壓力越平，越不容易空蝕。66 系列把最大厚度放在 45% 弦長，也是同樣的考量，這和航空常用的 NACA 四位數翼型（最大厚度在 30%）不同。

拖動 t/c 和 f/c，或直接載入 DTMB 4119 在不同半徑的剖面：根部又厚又短，為了強度；葉尖很薄；0.7R 附近最接近一般的翼型。

這是理想攻角下的薄翼理論負載。偏離理想攻角時導緣會出現吸力尖峰，空蝕的章節會用桶形圖討論。

DTMB 4119

1.3側斜與縱傾：把剖面沿螺旋面挪動

剖面的形狀決定了，還要決定它放在哪裡。各半徑剖面的弦長中點連成中弦線。從轂中心垂直槳軸往外拉的一條直線叫母線，是畫圖和加工的基準。

側斜：把剖面沿自己的螺旋線往後（逆旋轉方向）挪一個角度 θs，葉片彎成鐮刀形。各半徑的剖面因此不會同時掃進船尾的高伴流區，振動和船殼上的脈動壓力都會降低。

縱傾：把剖面沿軸向往下游挪 xR，葉片向後倒，可以加大和船殼的間隙。

側斜是沿螺旋線移動，所以也會順便帶來軸向位移，稱為側斜誘導縱傾：

xm = xR + r θs tan φ

側視圖上看得最清楚：只加側斜、不加縱傾，中弦線也會往後倒。高側斜槳常故意給一點反向縱傾，把葉尖拉回來。試著把側斜拉到 45°，再找出讓葉尖回到母線上的縱傾角。

側斜沿半徑採二次分布 θs = θtip ((r − rh)/(R − rh))²，縱傾採直線，弦長、螺距都用 DTMB 4119。實際的槳會依設計調整這兩條分布。

1.4面積比：葉片占了盤面多少

葉片面積和盤面積 πR² 的比值，是螺旋槳最常被引用的參數之一。展開面積只看弦長，等於把每個剖面攤平排在一起；投影面積是從船尾看過去，葉片在盤面上遮住的部分：

EAR = Z/(πR²) ∫ c dr
PAR = Z/(πR²) ∫ c cos φ dr

剖面斜放在螺旋面上，從船尾看只剩 c cos φ 的寬度，所以 PAR 永遠比 EAR 小，螺距越大差越多。DTMB 4119 的 EAR 算出來是 0.607（文獻標稱 0.60），PAR 大約是它的八成。

面積比主要由空蝕決定。推力一定時，面積越小，單位面積的負載越大，葉背壓力越低，越容易空蝕；面積越大，摩擦阻力越大，效率越低。葉數則和振動頻率、轂的空間有關：同樣的面積比，葉數越多，每片越窄。

嚴格來說，沿螺旋面量的伸張面積（developed area）和展開面積（expanded area）略有不同，工程上常視為相同。投影面積這裡忽略了拱度與厚度。
